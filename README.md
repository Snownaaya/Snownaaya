### 01 — About me

I'm a Unity Developer focused on gameplay systems, software architecture, and maintainable code.

I enjoy designing modular game systems, applying SOLID principles, and using reactive and event-driven approaches to build loosely coupled components. I'm particularly interested in how architectural decisions affect a game's extensibility, testability, and long-term maintainability.

I value clear abstractions, explicit dependencies, and pragmatic solutions over unnecessary complexity.

### 03 — Engineering principles

- **SOLID & OOP** — clear responsibilities and cohesive abstractions.
- **Decoupled architecture** — explicit dependencies and reduced coupling.
- **Reactive programming** — event-driven communication and state management.
- **Pragmatism** — the simplest design that solves the actual problem.

> Good architecture doesn't make code more complicated. It makes complexity manageable.
